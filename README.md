# **Loja de Cupcakes**

Projeto Integrador Transdisciplinar em Engenharia de Software II - Cruzeiro do Sul Virtual

Esse é um projeto de uma loja online de cupcakes. Ele se trata de um trabalho acadêmico.

## Pré-requisitos
- Node.js versão 18+ (recomendada 20+)

## Setup
- Abra dois terminais (um para Back-End e um para Front-End)
- Instale as dependências:
  - Back-end: `cd backend`
              `npm install`
  - Front-end: `cd frontend`
               `npm install`
## Executar
- Backend API:
  - `cd backend`
  - `npm run dev`
- Frontend:
  - `cd frontend`
  - `npm run dev`
  - Abra o URL mostrado
